# KursusKu

Project praktikum Pemrograman Web III menggunakan Laravel.

## Requirement
- PHP 8.3 atau lebih baru
- Composer
- Laravel
- Laragon atau web server lokal

## Cara Menjalankan
1. Buka terminal pada folder project.
2. Jalankan composer install.
3. Siapkan file .env jika diperlukan.
4. Jalankan php artisan key:generate jika diperlukan.
5. Jalankan php artisan serve.
6. Buka alamat yang muncul di terminal.
